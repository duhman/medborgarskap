This walkthrough shows actual ChatGPT test screenshots in workflow order. It is a silent sequence of still screenshots, not a continuous screen capture. Turn on captions for the test descriptions.

What is tested

  1. Search the public study corpus, then fetch a chapter with canonical and official UHR source links.
  2. Distinguish question-review dates from summary verification; show saved status and per-source FAQ dates.
  3. Return an honest empty result for an unmatched search.
  4. Explain that private progress, arbitrary URLs and personal citizenship decisions are outside the tools' scope.

The two tools are anonymous and read-only. The service never fetches a user-supplied URL and cannot read local practice answers, progress or accounts. The production HTTP checks separately verify invalid-input, private/write-tool and origin rejection. A refusal in a conversation does not itself test an HTTP rejection.
